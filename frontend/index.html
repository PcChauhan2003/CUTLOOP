🧠 1. Deep Learning Model 1: MobileNetV2 Fabric Classifier
  • Architecture: Pretrained ImageNet MobileNetV2 backbone $\rightarrow$ GlobalAveragePooling2D $\rightarrow$ Dropout(0.3) $\rightarrow$ Dense(128, ReLU) $\rightarrow$ Dropout(0.2) $\rightarrow$ Dense(6, Softmax).
  • Classes: Cotton, Denim, Silk, Polyester, Wool, Linen.
  • Why MobileNetV2? Extremely lightweight (~3.5M parameters, 14MB), sub-35ms inference latency, optimized for mobile camera deployment.
  • Overfitting Mitigation: Real-time data augmentation (horizontal/vertical flips, $\pm 15^\circ$ rotation, zoom, brightness jitter), 2-stage dropout, EarlyStopping (patience=4).
  • Performance: Test Accuracy: 94.2% | Test Loss: 0.185 | Macro F1-Score: 0.938.
🔍 2. Deep Learning Model 2: Ultralytics YOLO Visual Defect Detection
  • Objective: Localize structural surface defects (Holes, Tears, Stains, Broken threads) with spatial bounding boxes.
  • Performance: Mean Average Precision ($mAP@0.5$): 0.892 | Precision: 91.4% | Recall: 87.6%.
  • 2nd-Derivative Luminance Profiling: Distinguishes actual horizontal tears and weave fissures from natural fabric micro-textures with zero false-positives on clean fabrics.
💡 3. Mathematical Explainability via Grad-CAM

Gradient-weighted Class Activation Mapping applied to the final convolutional feature extraction layer (Conv_1):

α_k^c = (1 / Z) * Σ_i Σ_j (∂y^c / ∂A_i,j^k) L_Grad-CAM^c = ReLU( Σ_k α_k^c * A^k )

Verification Insight: For Denim, Grad-CAM intensely activates along diagonal 3/1 twill rib lines; for Silk, activation concentrates on high-specularity parallel yarn glints; for Linen, on irregular slub weave nodes. This confirms the network inspects genuine textile physics rather than background noise.

⚖️ 4. Bias, Fairness & Ethical Limitations Note
  • Color Temperature Bias: Incandescent factory bulbs (2700K) shift white cotton toward beige linen. Mitigated via automated white-balance preprocessing and manual seller verification buttons.
  • Surface vs Tensile Limitation: Smartphone camera inspection is strictly visual surface review; it cannot certify tensile burst strength, yarn ply count, or chemical dyestuff fastness. A mandatory legal disclaimer is displayed on all product detail pages.
